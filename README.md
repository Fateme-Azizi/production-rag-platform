# Production RAG Platform

A production-grade Retrieval-Augmented Generation (RAG) platform designed to explore modern AI engineering practices for building reliable, scalable, and trustworthy knowledge retrieval systems.

This project focuses on production-oriented architecture, evaluation engineering, guardrails, and system reliability. The goal is to build an end-to-end platform that demonstrates how enterprise AI applications can deliver accurate, evidence-based responses over large document collections.

---

## Features

- Document ingestion (PDF, DOCX, TXT)
- Semantic search and Retrieval-Augmented Generation (RAG)
- Source-aware responses with citations
- Evaluation engineering
- LLM-as-a-Judge
- Guardrails and hallucination mitigation
- Modular, production-oriented architecture
